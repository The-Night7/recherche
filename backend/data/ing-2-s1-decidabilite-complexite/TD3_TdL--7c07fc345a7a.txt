Rappels et notations
Lemme d’Arden
Soient A un alphabet etX, B, C trois langages définis surA∗.
Une solution de l’équationX = BX + C est
X = B∗C
Quelques propriétés utiles pour l’algorithme des quotients gauches :
• X ∗ = X + ∪ ε = X + + ε l’union ∪ est équivalente au signe+ (pas celui en exposant)
• X + = XX ∗ on en déduit :X ∗ = XX ∗ + ε
• x−1x = ε
• x−1Y = ∅ si le langageY ne contient aucun mot commencant parx
• On en déduit par exemple : x−1y = ∅ x−1ε = ∅
• Note : ∅ + X = X ∅.X = ∅ x−1∅ = ∅
• x−1(X + Y ) = x−1X + x−1Y
