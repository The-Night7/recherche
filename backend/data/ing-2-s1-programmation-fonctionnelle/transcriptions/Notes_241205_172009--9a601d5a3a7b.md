# Programmation fonctionnelle — Notes sur foldLeft, foldRight et la récursivité terminale

La page porte la mention « P39 Scala ».

## Repliement à gauche et à droite

Les arbres et les chaînes d’opérations de la page donnent, pour `List(a1, a2, a3, a4)` et un accumulateur initial `acc` :

```text
foldLeft : op(op(op(op(acc, a1), a2), a3), a4)
foldRight : op(a1, op(a2, op(a3, op(a4, acc))))
```

Le repliement à gauche traite les éléments de gauche à droite. Celui à droite les traite de droite à gauche, avec l’accumulateur en second argument de l’opération.

Pour `foldLeft`, les étapes de l’accumulateur sont :

```text
acc
op(acc, a1)
op(op(acc, a1), a2)
op(op(op(acc, a1), a2), a3)
op(op(op(op(acc, a1), a2), a3), a4)
```

Pour `foldRight`, elles sont :

```text
acc
op(a4, acc)
op(a3, op(a4, acc))
op(a2, op(a3, op(a4, acc)))
op(a1, op(a2, op(a3, op(a4, acc))))
```

## Arbres d’expressions arithmétiques

Pour l’expression écrite `2 + 3 * 6 + 7`, les arbres de la page illustrent :

$$((2+3)\times6)+7=37\quad\text{(association à gauche)},$$

$$2+(3\times(6+7))=41\quad\text{(association à droite)}.$$

Pour `3 * 7 + 2 * 5 - 7` :

$$(((3\times7)+2)\times5)-7=108\quad\text{(à gauche)},$$

$$3\times(7+(2\times(5-7)))=9\quad\text{(à droite)}.$$

> **Erreurs du manuscrit :** l’arbre de droite du second exemple porte le résultat 33. Dans cet arbre, l’étape $5-7$ y est évaluée à 2, au lieu de $-2$. Les résultats rectifiés ci-dessus suivent les parenthésages dessinés. Ces arbres illustrent des associations ; ils n’appliquent pas les priorités usuelles à l’expression non parenthésée.

## Exemple avec la liste (2, 3, 1, 2, 2)

### foldLeft

La fonction manuscrite est $f(acc,a)=2acc^2a$, avec accumulateur initial 1. La page écrit `2 * (acc ** 2) * a`.

Les étapes visibles sont :

$$f(1,2)=4,\qquad f(f(1,2),3)=f(4,3)=96,$$

puis $f(f(f(1,2),3),1)=f(96,1)=\ldots$. L’arbre s’arrête avant la fin du calcul.

L’écriture de l’appel est donnée sous la forme `foldleft(1){ (acc, a) => 2 * (acc ** 2) * a }`.

### foldRight

La fonction est cette fois $f(a,acc)=2a^2acc$, avec accumulateur initial 1. L’arbre se lit de bas en haut :

$$f(2,1)=8,\quad f(2,8)=64,\quad f(1,64)=128,\quad f(3,128)=2304,$$

puis $f(2,2304)$, soit le développement

$$f(2,f(3,f(1,f(2,f(2,1))))).$$

> **Erreur du manuscrit :** le résultat final est écrit 9216. Avec la fonction indiquée, $f(2,2304)=2\times2^2\times2304=18432$.
>
> **Notation du code :** `**` est utilisé dans les notes pour le carré. Pour un `Int` Scala standard, on écrit ici `acc * acc` ou `a * a` ; les noms de méthodes sont `foldLeft` et `foldRight`.

## Exemple avec une condition sur l’accumulateur

La page donne

```text
g(acc, a) =
  si acc > 7 : acc + a
  sinon : acc * a
```

Les arbres représentent les valeurs suivantes pour la même liste et l’accumulateur 1 :

| Étape | Accumulation de gauche à droite | Accumulation de droite à gauche |
| --- | ---: | ---: |
| Valeur initiale | 1 | 1 |
| Premier élément traité | 2 | 2 |
| Deuxième | 6 | 4 |
| Troisième | 6 | 4 |
| Quatrième | 12 | 12 |
| Cinquième | 14 | 14 |

Les deux arbres ont pour résultat 14. Pour le parcours depuis la droite, l’accumulateur est le second argument de la fonction passée à `foldRight` ; c’est toujours lui qui est testé contre 7.

## Récursivité terminale

Les notes mentionnent une fonction $f$ qui se termine par un appel récursif à une fonction $g$, et le stockage du résultat intermédiaire dans l’accumulateur. Le schéma oppose les opérations en attente à une transmission par `acc`.

La photographie donne deux formes de factorielle. Leur indentation et leur nommage sont normalisés ci-dessous ; les notes omettent certains types et emploient alternativement `FactorielleBis` et `Factorielle_bis`.

### Factorielle avec accumulateur

```scala
def factorielle(n: Int): Int = {
  def factorielleBis(n: Int, acc: Int): Int = {
    if (n <= 1) acc
    else factorielleBis(n - 1, n * acc)
  }
  factorielleBis(n, 1)
}
```

### Factorielle récursive directe

```scala
def factorielle(n: Int): Int = {
  if (n <= 1) 1
  else n * factorielle(n - 1)
}
```

Dans la première forme, l’appel récursif est la dernière opération. Dans la seconde, une multiplication reste à effectuer après le retour de l’appel.
