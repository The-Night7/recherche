— On considère qu’un arbre tel que celui présent sur la figure suivante, peut permettre de stocker des mots. La première

dans l’arbre, et qui va retourner 0 sinon.

Exercice 3 (A VL : Suppression de noeud (5 pt) )
Soit la structure d’un arbre de type AVL :
typedef struct _node{
int elt;
struct _node* fg;
struct _node* fd;
int eq;
} Arbre;
Coder la fonction de suppression d’un noeud d’un arbre de type AVL.
Le prototype de cette fonction est le suivant :Arbre* removeAVL(Arbre* pArbre, int value, int* h) .
Cette fonction doit en plus de supprimer le noeud recherché, mettre à jour les équilibres des noeuds impactés.
En cas de noeud à supprimer ayant deux enfants, la fonction doitaller chercher le remplaçant dans le sous-arbre
droit.
On supposera que la fonctionArbre* equilibrageAVL(Arbre* pArbre); existe et donc peut être appelée.
Exercice 4 ( Shell : Débit d’attractions d’un fameux parc Allemand (6 pt) )
Un parc d’attraction souhaite faire le point sur le débit horaire (nombre de personnes/heure à embarquer dans une
attraction) de ses montagnes russes.
L’objectif de cet exercice est d’écrire un script shell permettant d’analyser les statistiques de fréquentation des attractions
qui sont reportées dans un fichierattractions.txt. Chacune des lignes de ce fichier est au format suivant :
<nom_attraction>-<nombre_personnes>-<heures_ouvertes>
Exemple de fichierattractions.txt :
Voltron-14400-8
SilverStar-15300-9
BlueFire-9600-8
Poseidon-0-0
Wodan-14000-10
À partir de ce fichier, écrire un script Shell qui prendra en paramètre le nom d’un fichier au format indiqué ci-dessus.
Une documentation de différentes commandes est disponible à la fin de ce sujet.
1. Vérifier le nombre d’arguments et la validité de ceux-ci. Afficher des messages d’erreur appropriés en cas de problème.
Si le fichier n’existe pas ou n’est pas accessible, signaler l’erreur et arrêter le script.
2. Afficher uniquement le nom de toutes les attractions listées dans le fichier.
Aide pour la suite : l’instruction suivante
for ligne in $(cat "fichier")
permet de parcourir chaque ligne defichier.
3. Afficher la ligne complète de l’attraction ayant accueilli le plus de personnes.
4. Identifier les attractions ayant0 en nombre de personnes et en heures ouvertes (les attractions fermées). Générer un
nouveau fichier coasters_fonctionnels.txt comportant uniquement les informations des attractions ouvertes.
5. Générer un nouveau fichierdebit.txt contenant les informations complètes des attractions ouvertes, accompagnées
du débit horaire entier (calculé commenombre_personnes / heures_ouvertes ), formaté comme suit :
<nom_attraction>;<nombre_personnes>;<heures_ouvertes>;<debit_horaire>
6. Parmis les attraction fonctionnelles, afficher les deux attractions ayant le meilleur débit horaire et les deux attractions
ayant le moins bon débit horaire.

grep - print lines that match patterns
SYNOPSIS
grep [OPTION...] PATTERNS [FILE...]
grep [OPTION...] -e PATTERNS ... [FILE...]
grep [OPTION...] -f PATTERN_FILE ... [FILE...]
DESCRIPTION
grep searches for PATTERNS in each FILE. PATTERNS is one or patterns separated by
newline characters, and grep prints each line that matches a pattern.
OPTIONS
Matching Control
-f FILE, --file=FILE
Obtain patterns from FILE, one per line. If this option is used multiple times
or is combined with the -e (--regexp) option, search for all patterns given.
The empty file contains zero patterns, and therefore matches nothing.
-i, --ignore-case
Ignore case distinctions, characters that differ only in case match each other.
-v, --invert-match
Invert the sense of matching, to select non-matching lines.
Output Line Prefix Control
-n, --line-number
Prefix each line of output with the 1-based line number
within its input file.
————————————————-
sort - sort lines of text files
DESCRIPTION
-d, --dictionary-order
consider only blanks and alphanumeric characters
-f, --ignore-case
fold lower case to upper case characters
-g, --general-numeric-sort
compare according to general numerical value
-n, --numeric-sort
compare according to string numerical value
-r, --reverse
reverse the result of comparisons
--sort=WORD
sort according to WORD: general-numeric -g, human-numeric
-h, month -M, numeric -n, random -R, version -V
————————————————-
tr - translate or delete characters
SYNOPSIS
tr [OPTION]... STRING1 [STRING2]
DESCRIPTION
Translate, squeeze, and/or delete characters from standard input,
writing to standard output. STRING1 and STRING2 specify arrays
of characters ARRAY1 and ARRAY2 that control the action.
-d, --delete
delete characters in ARRAY1, do not translate
-s, --squeeze-repeats
replace each sequence of a repeated character that is
listed in the last specified ARRAY, with a single
occurrence of that character
[:digit:]
all digits
[:lower:]
all lower case letters
[:upper:]
all upper case letters
