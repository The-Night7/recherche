II. Comprendre le problème et le programme 
Algorithme de calcul de la suite de Fibonacci codé en C++, parallélisez ce code 
suivante  F(0)=0 et F(1)=F(2)=1 et pou tout n ≥2 alors F(n) = F(n-1) + F(n-2)  avec 
int fibonacci(int n) 
{ 
  int u = 0; 
  int v = 1; 
  int i, t; 
 
  for(i = 2; i <= n; i++) 
  { 
    t = u + v; 
    u = v; 
    v = t; 
  } 
  return v; 
}
