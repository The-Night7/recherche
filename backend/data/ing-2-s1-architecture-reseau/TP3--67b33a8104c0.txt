                TP 3 : Routage statique et routage dynamique 
 
 
Partie 1 : Configuration des réseaux  
Etape 1 : 
 
L’adresse du sous-réseau 172.16.1.0 – 255.255.255.0 du réseau de classe B sera utilisé pour 
l’université. Vous serez en Charge de déployer ce plan d’adressage sur les 5 départements de 
l’université avec les  besoins ci-dessous : 
 
Département 1: 25 adresses pour les PCs + Equipements réseau 
Département 2: 25 adresses pour les PCs + Equipements réseau 
Département 3: 25 adresses pour les PCs + Equipements réseau 
Département 4: 25 adresses pour les PCs + Equipements réseau 
Département 5: 29 adresses pour les PCs + Equipements réseau et Serveurs 
 
Chaque département devrait être dans son propre sous -réseau. Un routeur central avec 5 interfaces 
sera utilisé pour interconnecter les 5 réseaux et permettra de créer une topologie en étoile. 
 
Il faudrait tout d’abord déterminer pour chaque Département, l’adresse du sous -réseau, le masque 
correspondant, la plage des adresses à affecte r au PCs, l’adresse Broadcast ainsi que l’adresse de la  
passerelle. La passerelle devrait être la dernière adresse dans chaque sous-réseau. En deuxième étape, 
il faudrait implémenter la solution proposée dans Packet Tracer.

Etape 2 : 
 
On veut communiquer un autre réseau de classe C (192.168.1.0 255.255.255.0)  au réseau déployé 
dans le TP précèdent. Ce réseau  est localisé au Campus Nord (éloignée géographiquement de 
quelques kilomètres du Campus Sud). Une liaison spécialisée  de 2048 kbps ent re les deux  campus 
est mise en place.  
 
Votre tâche dans ce TP est d’accomplir ce qui suit: 
 
- Ajouter aux routeurs les cartes qu’il faut pour effectuer ce raccordement 
- Définir un plan d’adressage pour la liaison Point-a-Point 
- Configurer le routage entre les deux réseaux de façon statique et ensuite de façon dynamique.

Configuration des interfaces : 
 
Router0>enable 
Router0#Config Terminal

déduire les noms des interfaces 
Router0(config)#bandwidth 2048 
Router0(config)#ip address 10.10.10.1 255.255.255.252

Router1>enable 
Router1#Config Terminal 
Router1(config)# interface Serial0/3/0 
Router1(config)#bandwidth 2048

Router1(config)#no shutdown 
 
N.B : N’oublier pas de configurer l’interface Ethernet du nouveau routeur Routeur1 et d’affecter les 
adresses IP au PCs du campus Nord. Voir l’étape 1 de cette partie pour un rappel des instructions. 
 
Partie 2 : Configuration du routage statique entre les deux réseaux: 
 
Router0(config)#ip route 192.168.1.0 255.255.255.0 10.10.10.2 
 
Router1(config)#ip route 172.16.1.0 255.255.255.0 10.10.10.1 
 
La commande pour visualiser la table de routage : 
 
Router0# show ip route 
 
Les routes statiques sont marques avec un S.

Partie 3 : Configuration du routage dynamique : 
 
Router0(config)#no ip route 192.168.1.0 255.255.255.0 10.10.10.2 <<< On commence par enlever les 
routes statiques 
Router0(config)#router rip <<< On utilise le protocole RIP pour le routage dynamique 
Router0(config-router)#network 10.0.0.0 <<< On ajoute les réseaux auxquels le routeur est 
connecté 
Router0(config-router)#network 192.168.1.0 
 
Router1(config)#no ip route 172.16.1.0 255.255.255.0 10.10.10.1 
Router1(config)#router rip 
Router1(config-router)#network 10.0.0.0 
Router1(config-router)#network 172.16.1.0 
 
La commande pour visualiser la table de routage : 
 
Router0# show ip route 
 
Les routes RIP sont marques avec un R.
