PROJETS PROGRAMMA TIONS ET MA THÉMA TIQUES
Code torique
Le code torique est un modèle quantique simple permettant d’éviter les
erreurs faites par un ordinateur quantique. Ce projet est plus théorique.
Nous étudierons le code torique comme modèle canonique de correction
d’erreurs topologique, en partant d’un réseau 2D de qubits et de l’idée que
l’information logique est stockée globalement plutôt que localement. Nous
construirons les stabilisateurs (étoiles et plaquettes), identifierons l’espace
des états du code et interprèterons les mesures de syndrome comme la dé-
tection d’excitations (paires d’anions) créées par des erreurs locales de type
X ou Z. Noussuivronsensuite, surdesexemplesguidés, commentunechaîne
d’erreurs produit un bord de syndrome, comment une procédure de matching
permet de choisir une correction, et pourquoi des boucles non contractiles
correspondent à des erreurs logiques. Nous concluerons par une discussion
sur la robustesse qui croît avec la taille du réseau, la notion de distance du
code, et une ouverture vers le code de surface et la tolérance aux pannes
dans des dispositifs réalistes. Nous ferons une implémentation numérique.
