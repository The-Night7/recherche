1.4 Les expressions régulières
1. Remplacer toutes les lettre H par la lettre Z dans le ﬁchierhp1.txt et enregistrer les
modiﬁcations réalisées dans le ﬁchierhp1Modif1.txt
Réponses
sed -e ’s/H/Z/g’ hp1.txt > hp1Modif.txt
2. Remplacer les lettres m en début de ligne par un M et enregistrer les modiﬁcations
réalisées dans le ﬁchierhp1Modif2.txt
Réponses
sed -e ’s/∧m/M/g’ hp1.txt > hp1Modif2.txt
3. Remplacer les lettres précédées d’un espace par une virgule et enregistrer les modiﬁ-
cations réalisées dans le ﬁchierhp1Modif3.txt
Réponses
sed -e ’s/ [a-z|A-Z]/ ,/g’ hp1.txt > hp1Modif3.txt
4. Remplacer leslettres, parun+ etleslettres; parun@ etenregistrerles modiﬁcations
réalisées dans le ﬁchierhp1Modif4.txt
Réponses
sed -e ’s/,/+/g;s/;/@/g’ hp1.txt > hp1Modif4.txt
5. Enregistrerlecontenudehp1.txt,exceptéleslignes2,3et4,dansleﬁchier hp1Modif5.txt
Réponses
sed -e ’2,4d’ hp1.txt > hp1Modif5.txt

(a) les noms des éléments commençant par "a" et dont la deuxième lettre est "s" ou

1.5 Les variables prédéﬁnies du shell
1. Tapez les 3 commandes suivantes dans votre terminal :printenv, env et set. A
votre avis, que font ces commandes?
Réponses
- printenv←aﬃche les variables d’environnement (cde ancienne)
- env←aﬃche les variables (pareil que printenv)
- set←aﬃche en plus les variables locales.
2. Qu’est ce que le prompt? Quelle est la variable privée qui représente le prompt?
Réponses
Le prompt est une invite de commande. Il indique de manière générale le nom
de l’utilisateur, de la machine et du chemin du répertoire où on se trouve.
La variable estPS1
