Théorème 1: (Equivalence des normes)
Soit E un espace vectoriel de dimension ﬁnie. Alors, toutes les normes sur
E sont équivalentes.
Démonstration : admis.
De manière très intuitive, vous savez que l’on peut grâce à la norme déﬁnir la
distance entre deux points. On se propose ici de déﬁnir ce qu’est une distance
Déﬁnition 3: (Distance)
Soit X un ensemble quelconque. L’applicationd, de X× X −→ R+,
est une distance surX, si et seulement si, elle vériﬁe :
1. ∀(X,Y )∈X 2, d(X,Y ) = 0⇐⇒X =Y
2. ∀(X,Y )∈X 2, d(X,Y ) =d(Y,X )
3. ∀(X,Y,Z )∈X 3, d(X,Y )≤d(X,Z ) +d(Z,Y )
Remarque : en réalité les propriétés demandées sont triviales :
1. La seule façon pour que la distance entre deux points soit nulle est que
les deux points soient confondus.
2. La distance est symétrique. La distance entreX et Y est la même que la
distance entreY et X.
3.
d(X,Y )≤d(X,Z ) +d(Z,Y ) : si je passe par un autre pointZ pour aller de
X à Y, au mieux je ne réduis pas la distance au pire je fais un détour.
