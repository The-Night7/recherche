Exercice 1 : Questions de cours (5 points) 
1. Citer deux différences entre OpenMP et MPI 
Le OpenMP (multithreading) est basé sur la communication par mémoire partagée entre 
les threads par contre MPI (multiprocessing) est basé sur la communication par passage 
de message (ou envoi et la réception de messages) entre les processus 
 OpenMP est souvent utilisé pour accélérer les calculs sur les processeurs multicœurs, 
par contre le MPI est utilisé pour des architectures distribuées.   
 
2. Donner au moins deux aspects à considérer pour améliorer le passage à l'échelle 
(Scalability) d'un code parallèle. 
 Minimiser communications, exploiter la localité des données, équilibrage de charge, 
minimisation des synchronisations 
 
3. citer deux  avantages et deux inconvénients de l’utilisation des barrières de 
synchronisation? 
Avantages 
 Coordination des Threads/Processus : Les barrières de synchronisation permettent de 
coordonner l'exécution de plusieurs threads ou processus en garantissant qu'ils 
atteignent tous un point commun avant de continuer 
 Ordonnancement et Planification : Les  barrières de synchronisation peuvent être 
utilisées pour contrôler l'ordre d'exécution des threads ou processus, ce qui peut être 
utile dans certains cas pour garantir un comportement spécifique de l'application 
Inconvénients 
 Coût de Performance : L'utili sation de barrières de synchronisation peut entraîner un 
surcoût de performance, car les threads ou processus doivent attendre que tous les 
autres atteignent la barrière avant de pouvoir continuer. Cela peut entraîner des temps 
d'attente et réduire l'efficacité du parallélisme. 
 Possibilité de Blocage : Si un thread ou un processus échoue pour atteindre la barrière, 
cela peut entraîner un blocage (mais non pas l' interblocage ou deadlock) de tous les 
autres threads ou processus qui attendent à la barrière

Exercice 2 : Évaluation de la performance (5 points) 
1. Un programme parallèle passe 6% de son temps d’exécution dans les opérations 
exécutées sur un seul processeur. Quel est le nombre minimal de processeurs pour que 
le programme parallèle produise une accélération de 10 par rapport au programme 
sequentiel? 
Speedup= T1/Tp , avec Tp= (0.06+(1-0.06)/p) *T1 = (0.06+0.94/p)*T1  
speedup= 1/(0.06+0.94/p)= 10  donc 0.4*p= 9.6  il résulte p=24 processeurs 
 
2. Un programme a une accélération de 8 sur 12 processeurs. Quelle est la fraction du 
temps d’exécution séquentiel qu i peut correspondre à des opérations purement 
séquentielles ? 
On a p=12,   Speedup=8 
Soit f la fraction de temps d’exécution séquentiel 
Speedup= T1/Tp , avec Tp= (f+(1-f)/p) *T1 donc 
speedup= 1/(f+(1-f)/12)= 8  donc 88*f= 4  il résulte f=0.045 (4.5%)

#include <stdio.h> 
#include <stdlib.h> 
#include <mpi.h> 
#define LETAG 1 
 
int main(int argc, char *argv[]) { 
 int rang, np; 
 MPI_Status status; 
 
 MPI_Init(&argc, &argv); 
 MPI_Comm_rank(MPI_COMM_WORLD, &rang); 
 MPI_Comm_size(MPI_COMM_WORLD, &np); 
 
 if (np != 5) { 
      printf("Erreur: Ce programme nécessite exactement 5 processus.\n"); 
      MPI_Abort(MPI_COMM_WORLD, 1); 
 } 
 
 int a, b, op; 
 if (rang == 0) { 
     // Initialisation des nombres et de l'opérateur 
     a = atoi(argv[1]); 
     b =  atoi(argv[2]); 
     op = atoi(argv[3]); 
 
     // Envoi des nombres et de l'opérateur aux autres machines 
     for (int i = 1; i < np; ++i) { 
         MPI_Send(&a, 1, MPI_INT, i, LETAG, MPI_COMM_WORLD); 
         MPI_Send(&b, 1, MPI_INT, i, LETAG, MPI_COMM_WORLD); 
         MPI_Send(&op, 1, MPI_INT, i, LETAG, MPI_COMM_WORLD); 
     } 
 }

#include <stdio.h> 
#include <stdlib.h> 
#include <time.h> 
#include <mpi.h> 
 
#define MAX_ITERATIONS 5 
 
int main(int argc, char *argv[]) { 
 int rang, np; 
 MPI_Init(&argc, &argv); 
 MPI_Comm_rank(MPI_COMM_WORLD, &rang); 
 MPI_Comm_size(MPI_COMM_WORLD, &np); 
 MPI_Status status; 
 
 int value = 1; 
 
 for (int iter = 0; iter < MAX_ITERATIONS; ++iter) { 
     int sum = 0; 
 
     // Échange des valeurs entre les processus 
     for (int i = 0; i < np; ++i) { 
         if (i != rang) { 
             int received_value; 
             MPI_Send(&value, 1, MPI_INT, i, 0, MPI_COMM_WORLD); 
             MPI_Recv(&received_value,1, MPI_INT, i, 0, MPI_COMM_WORLD, &status); 
             sum += received_value; 
         } 
    } 
 
    // Mise à jour de la valeur en fonction de la somme des valeurs partagées 
     value += sum; 
 
     // Synchronisation des processus avant l'échange de valeurs 
     MPI_Barrier(MPI_COMM_WORLD); 
 
     // Affichage de la valeur mise à jour 
     printf("Processus %d, Itération %d : valeur = %d\n", rang, iter, value); 
 } 
 
 MPI_Finalize(); 
 return 0; 
}
