Exercice 2 : Loi de Newton (Refroidissement)
1. Modélisation
    La loi stipule que la vitesse de refroidissement T ′ (t) est proportionnelle à la différence (T (t) −
Tair (t)). On traduit cela par l’équation linéaire :

                 T ′ (t) = −k(T (t) − Tair (t))     ⇐⇒     T ′ (t) + kT (t) = kTair (t) (E)

avec k > 0 une constante (coefficient de transfert thermique).

2. Cas Tair = 20◦ C (Constant)
   L’équation est T ′ + kT = 20k. C’est une EDO linéaire à coefficients constants.
   — Solution Homogène (vh ) : T ′ + kT = 0 =⇒ vh (t) = Ce−kt .
   — Solution Particulière (vp ) : Tair étant constante, une solution constante évidente est vp (t) =
      20.
