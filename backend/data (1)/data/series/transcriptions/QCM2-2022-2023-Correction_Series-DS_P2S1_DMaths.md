# Correction — QCM3L Suites de fonctions, Préing 2

Le fichier est nommé « QCM2-2022-2023-Correction », mais son titre imprimé est « QCM3L Suites de Fonctions Préing2 ».

La zone d’identification comporte une grille de huit colonnes, chacune numérotée de 0 à 9, pour coder le numéro d’étudiant, ainsi qu’un cadre « Nom et prénom ». Consigne : coder le numéro d’étudiant, inscrire le nom puis le prénom ; les cases doivent être complètement noircies avec un stylo noir.

Les mentions **noircie** et **vide** ci-dessous reproduisent les cases du corrigé imprimé. Elles ne constituent pas une correction recalculée.

## Question 1

On considère la suite de fonctions définies par $f_n(x)=\frac{nx}{1+nx}$. Alors, la suite $(f_n)_{n\ge0}$ :

| Proposition | Case imprimée |
| --- | --- |
| Converge uniformément sur $[1,+\infty[$ | Noircie |
| Converge uniformément sur $[a,1]$, $a\in]0,1[$ | Noircie |
| Converge simplement vers une fonction constante sur $[0,1]$ | Vide |
| Converge uniformément sur $]0,1]$ | Vide |

## Question 2

Soit $(f_n)_n$ définie par $f_n(x)=\frac{\sin(nx)}{n!}$. Alors, la suite $(f_n)_n$ :

| Proposition | Case imprimée |
| --- | --- |
| Converge uniformément sur $\mathbb R$ | Noircie |
| Converge uniformément sur $]-\infty,0[$ | Noircie |
| Converge uniformément sur $[0,2\pi]$ vers une fonction continue | Noircie |

## Question 3

On définit une suite de fonctions par $f_n(x)=x^2\sin\left(\frac1{nx}\right)$ pour $x\in\mathbb R^*$ et $f_n(0)=0$. Alors, la suite $(f_n)_{n\ge0}$ :

| Proposition | Case imprimée |
| --- | --- |
| Converge uniformément sur $[-2,2]$ | Noircie |
| Converge uniformément sur $[0,+\infty[$ | Vide |
| Converge uniformément sur $[0,2]$ | Noircie |
| Converge uniformément sur $\mathbb R$ | Vide |

> **Coquille de la source :** la suite est indiquée pour $n\ge0$, alors que la formule contenant $1/(nx)$ exige $n\ge1$.

## Question 4

Soit $(f_n)_n$ une suite de fonctions définies sur un intervalle $[a,b]\subset\mathbb R$ à valeurs réelles. Quelles sont les conditions nécessaires pour appliquer le théorème d’interversion limites-intégrales ?

| Proposition | Case imprimée |
| --- | --- |
| Pour tout $n\in\mathbb N$, $f_n$ est de classe $C^0$ sur $[a,b]$ | Noircie |
| La suite $(f_n')_n$ converge uniformément sur $[a,b]$ vers une fonction $g$ | Vide |
| La suite $(f_n)$ converge uniformément sur $[a,b]$ vers une fonction $f$ continue | Vide |
| La suite $\left(\int_a^b f_n(x)\,dx\right)_n$ est convergente | Vide |

> **Réserve sur le corrigé imprimé :** seule la première case est noircie. La continuité de chaque $f_n$ ne suffit pas, à elle seule, à autoriser l’interversion. La convergence uniforme est une hypothèse du théorème usuel sur un segment. Le marquage du document est conservé, sans lui substituer de nouvelles cases.
