7. Sommez le premier et dernier nombre du fichier à l’aide de la fonctionfscanf.

Exercice 4 (Ecriture d’un fichier JSON)
Il existe un type de fichier qui permet de stocker des structures de valeurs sous forme de chaine de caractères : le format
JSON
Le but de cet exercice est de créer une structure avec diverses informations (nous reprendrons la structureEtudiant des
TPs précédents) pour la parcourir et la stocker dans un fichierASCII au format JSON.
Si vous souhatez en savoir plus sur ce format de fichier, vous pouvez consulter la page wikipédia disponible ici :
https://fr.wikipedia.org/wiki/JavaScript_Object_Notation
Soit la structure Etudiant au format suivant :
typedef struct {
char* nom;
char* prenom;
int groupe;
float* notes;
}

ou les tabulations sont optionnelles pour le format JSON, mais sont utilisées ici pour plus de lisibilité) :
