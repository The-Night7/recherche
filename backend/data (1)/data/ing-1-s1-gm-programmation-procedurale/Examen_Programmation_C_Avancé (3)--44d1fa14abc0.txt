Partie 2 : Manipulation de chaînes et pointeurs (7 points)

1. Fonction de copie (3 points)

Écrivez une fonction `copyString` qui copie une chaîne source vers une chaîne destination en utilisant des pointeurs. La fonction doit arrêter la copie dès qu’elle atteint la fin de la chaîne source ou une longueur maximale spécifiée.

**Prototype :**
```c
void copyString(char* source, char* destination, int maxLength);
```

**Exemple :**
```
Source : "Programmation"
Max Length : 5
Destination : "Progr"
```


2. Recherche dans une chaîne (4 points)

Implémentez une fonction `findSubstring` qui recherche la première occurrence d’une sous-chaîne dans une chaîne principale. Retournez l’indice de début de la sous-chaîne si elle est trouvée, sinon -1.

**Prototype :**
```c
int findSubstring(char* str, char* substr);
```

**Exemple :**
```
Chaîne principale : "programmation en C"
Sous-chaîne : "gram"
Résultat : 3
```

2. Gestion de structures (4 points)

Définissez une structure `Personne` avec les champs suivants : nom (chaîne), âge (entier), et salaire (float). Écrivez un programme qui :
- Crée un tableau dynamique de `Personne`.
- Demande à l'utilisateur de remplir les informations pour `n` personnes.
- Affiche les informations de la personne ayant le salaire le plus élevé.

**Prototype des fonctions :**
```c
typedef struct {
    char nom[50];
    int age;
    float salaire;
} Personne;

void afficherPersonneAvecSalaireMax(Personne* personnes, int taille);
```

**Exemple d’exécution :**
```
Nombre de personnes : 3
Nom : Alice
Âge : 30
Salaire : 3500.00

Nom : Bob
Âge : 25
Salaire : 4500.00

Nom : Clara
Âge : 28
Salaire : 4000.00

Résultat : Bob, Âge : 25, Salaire : 4500.00
```

**Objectif :** Créez un programme principal qui :
1. Appelle la fonction `findSubstring` pour rechercher une sous-chaîne dans une chaîne donnée par l'utilisateur.
2. Appelle la fonction `selectionSort` pour trier un tableau d’entiers.
3.Ecrivez un Makefile qui permet de compiler et exécuter le programme

**Exemple d’exécution :**

Taille du tableau : 5
Entrez les éléments : 5 1 4 2 3
Tableau trié : [5, 4, 3, 2, 1]
