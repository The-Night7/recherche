Exercise 1 (Binary trees).
a. In a sbt project, deﬁne in ﬁle src/main/scala/BinaryTree.scala the BinaryTree[T] type describing
binary trees with labels of type T. A binary tree is either :
• an empty tree ;
• or a node with a label and left and right childs.
Type must provide following methods :
• size computes number of labels of tree ;
• height computes tree height ;
• contains(x : T) checks if x is a label in tree ;
b. Try to write size, height and contains as three special cases of one new method named fold.
c. Type parameter T should typically be covariant.
(i) What happens when T is set to be covariant ? Why ?
(ii) How to solve the problem while letting covariance ?
Exercise 2 (Rational numbers).
a. Build a sbt project.
b. Deﬁne in ﬁle src/main/Rational.scala the Rational type representing rational numbers with :
• exactly two constructors that may be used without keyword new :
– Rational(numerator : Int, denominator : Int) ;
– Rational(numerator : Int) ≡ Rational(numerator : Int, 1) ;
• arithmetic unary operators unary_-, inverse ;
• arithmetic binary operators +, -, *, / ;
• equality operator ;
• comparison operators using predeﬁned Ordered trait ;
• toString redeﬁned accordingly ;
Deﬁne also rational constants zero, one and inf (as 1/0).
c. Modify type Rational such that arithmetic binary operators, equality and comparison operators can
handle mixed parameters, i.e. with type Int and Rational.
