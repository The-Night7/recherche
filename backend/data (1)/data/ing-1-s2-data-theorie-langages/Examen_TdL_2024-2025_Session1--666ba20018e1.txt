Exercice 1 : Langages réguliers (6.5 pts) 
Soit le langage 𝐿 défini sur l'alphabet A = {𝑎, 𝑏} représentant l’ensemble de mots dont le reste de la division de 
|𝑤|𝑎 par 3 est égal à 1. Le nombre |𝑤|𝑎 est le nombre de lettres « a » dans un mot w. 
Formellement : 𝐿 = {𝑤 ∈  𝐴+ / |𝑤|𝑎 = 1[3] } 
1. Ecrire une grammaire régulière reconnaissant le langage 𝐿. 
2. Construire un automate à états finis pour ce langage. 
3. Construire puis résoudre le système d'équations de l'automate à états finis afin d'obtenir l'expression régulière 
reconnaissant 𝐿.  
Exercice 2 : Langages algébriques (7 pts) 
Soient A = {𝑎, 𝑏} l'alphabet et le langage 𝐿 = {𝑤 ∈  𝐴+/  |𝑤|𝑎 = 2 |𝑤|𝑏  et  |𝑤|𝑎 ≥ 1  } 
Le nombre |𝑤|𝑎 est le nombre de lettres « a » dans un mot w. 
Le nombre |𝑤|𝑏 est le nombre de lettres « b » dans un mot w. 
1. Ecrire une grammaire algébrique reconnaissant 𝐿 . 
2. Construire un automate à pile qui reconnaît les mots du langage 𝐿. 
3. Donner la forme normale de Chomsky de cette grammaire. 
4. Appliquer l’algorithme CKY pour déterminer si le mot « 𝒂𝒂𝒃𝒂𝒃𝒂 » appartient à ce langage. 
Exercice 3 : Langages récursivement énumérables (6.5 pts) 
Soit 𝐿 le langage représentant l’ensemble des mots défini sur l'alphabet  A = {𝑎, 𝑏} contenant au moins une 
occurrence de la séquence « 𝒂𝒃𝒃 » de façon que 𝐿 = {𝑤 ∈  𝐴+ / ∃(𝑢, 𝑣) ∈ 𝐴∗ × 𝐴∗ avec 𝒘 = 𝒖 𝑎𝑏𝑏 𝒗 }. 
1. Construire une machine de Turing calculatrice qui calcule le nombre d’apparition de « 𝒂𝒃𝒃 » dans un mot w 
de 𝐿. 
2. Donnez la définition formelle (sept ensembles) de votre machine de Turing.  
 
Note : La machine de Turing en mode calculateur doit repositionner la tête de lecture dans sa position initiale de 
départ.
