### Exercice 1 — Question de cours (3 pts)

1. Soit X une variable aléatoire suivant une loi géométrique de paramètre p ∈ ]0,1[.

— Expliquer ce que modélise une variable aléatoire qui suit une loi géométrique.

— Préciser l’ensemble X(Ω) des valeurs prises par X.

— Pour tout k ∈ X(Ω), donner la formule de P(X = k).

— Rappeler sans démonstration les expressions de E[X] et V(X).

2. Soit X une variable aléatoire continue de densité f.

— Rappeler la définition de sa fonction de répartition F.

— Donner les limites de F en −∞ et +∞ et le lien entre F et f.

### Exercice 2 — Intégrales généralisées (3 pts)

On considère les deux intégrales suivantes :

I₁ = ∫₀¹ ln(1+t)/√t dt et I₂ = ∫₁⁺∞ 1/[t(t²+1)] dt

1. Déterminer la nature de l’intégrale I₁.

2. Justifier la convergence de I₂ puis calculer sa valeur exacte.

Indication : déterminer a, b et c tels que, pour tout t ≥ 1 : 1/[t(t²+1)] = a/t + (bt+c)/(t²+1).

### Exercice 4 — Variables aléatoires discrètes (3 pts)

Un service informatique observe que son serveur tombe en panne en moyenne 1 fois par semaine. On suppose que les pannes sont rares et indépendantes les unes des autres. On modélise le nombre de pannes par semaine par X suivant une loi de Poisson de paramètre λ = 1.

1. Quelle est la probabilité qu’il n’y ait aucune panne dans la semaine ?

2. Quelle est l’espérance de X ? Démontrer la formule utilisée.

3. Le responsable veut que la probabilité d’avoir plus de 2 pannes dans une semaine soit inférieure à 0,1. Est-ce le cas ici ?

Valeurs approchées : e⁻² ≃ 0,14 ; e⁻¹ ≃ 0,37 ; e¹ ≃ 2,72 ; e² ≃ 7,39.

### Exercice 5 — Couple de variables aléatoires (5 pts)

Une urne contient 5 boules numérotées : 0, 0, 1, 1, 2. On effectue deux tirages successifs sans remise et on définit :

X = numéro de la première boule tirée ; Y = somme des numéros des deux boules tirées.

1. Donner la loi du couple (X,Y).

2. En déduire les lois marginales de X et Y. Interpréter la loi marginale de X dans le contexte de ce tirage.

3. Calculer E[X], E[Y], V(X) et V(Y).

4. Les variables X et Y sont-elles indépendantes ?

5. Calculer Cov(X,Y). Quel lien avec la question précédente ?

6. On pose Z = X+Y. Déduire des questions précédentes la valeur de V(Z).

### Exercice 6 — Variable aléatoire continue (4 pts)

Soit X une variable aléatoire continue dont la densité f est définie sur ℝ par :

f(t) = λt exp(−t²/2) si t ≥ 0 ; 0 si t < 0, où λ est une constante réelle.

1. Déterminer λ pour que f soit une densité.

2. Déterminer la fonction de répartition F.

3. Calculer P(X ≤ √(2 ln(2))).

4. Calculer E[X].

5. Calculer V(X).

Indications : utiliser une intégration par parties pour E[X] ; ∫₀⁺∞ exp(−t²/2) dt = √(π/2) ; pour V(X), poser s = t²/2.
