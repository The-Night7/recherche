Exercice 3
Soit f : R → R une fonction.
1. Donner la négation de : ∀x ∈ R, f (x) > 0 = ⇒x = 0 ou x ≥ 5.
2. On considère la proposition P : " f est périodique".
(a) Traduire mathématiquement P.
(b) Donner la négation de P.
Solution :
1.
∃x ∈ R, f (x) > 0 et x ⁄= 0 et x < 5.
2. (a)
∃T ∈ R, ∀x ∈ R, f (x + T ) = f (x).
(b)
∀T ∈ R, ∃x ∈ R, f (x + T ) ⁄= f (x).

Solution :
1. Récurrence Double : On considère une propriété P(n) dépendant de l’entier n ∈ N, et on
suppose que :
— P(0) et P(1) sont vrais,
— pour tout n ∈ N, si P(n) et P(n + 1) sont vrais, alors P(n + 2) est vraie.
Alors la propriété P(n) est vraie pour tout n ∈ N.
2. — Initialization : Nous avons
u0 = 2 = (−2)0 + 30 ; u1 = 1 = (−2)1 + 31.
La propositon et ainsi vraie pour n = 0 et n = 1.
