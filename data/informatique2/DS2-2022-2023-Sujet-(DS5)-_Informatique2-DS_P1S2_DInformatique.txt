Le démineur est un jeu-vidéo se déroulant sur unplateau carré . Des bombes cachées sont placées aléatoirement sur
les cases de ce tableau. Lorsqu’on choisi une case, si cette case contient une bombe, la partie est finie, sinon cette case est
révélée. Une case révélée indique le nombre de bombes dans les 8 cases adjacentes. Si ce nombre est égal à 0 (aucune bombe
dans les 8 cases autour) alors ces 8 cases sont révélées. Ce qui peut entrainer une réaction en chaîne dans les zones où les
bombes sont absentes jusqu’à ce qu’une case révélée contienne au moins une bombe dans ses cases voisines.
Dans cet exercice, nous allons écrire quelques fonctionnalités pour pouvoir programmer un démineur en C qui s’afficherait
sur un terminal.
