Exercice 14 : Conversion en hexadécimal

Rappel du Cours

entièreEet sa partie fractionnaireF.
—Partie entière (E) :On utilise la méthode desdivisions euclidiennes successives
par 16. On lit les restes de bas en haut(Support de cours, Algorithme 3.1.1, page
35).
—Partie fractionnaire (F) :On utilise la méthode desmultiplications successives
par 16. On lit les parties entières obtenues de haut en bas(Support de cours,
Algorithme 3.1.2, page 36).
—Chiffres hexadécimaux :A= 10,B= 11,C= 12,D= 13,E= 14,F= 15.

0,4×16 = 6,4→Partie entière =6
...

Conclusion
15,275 10 = (F,466...) 16

Exercice 15 : Représentation IEEE-754
Question :Calculer la représentation de 5,75 et 0,1 en simple et double précision.
Rappel du Cours
Un nombre est stocké au format IEEE-754 normalisé sous la formex= (−1) s×(1,m) 2×

—Double Précision (64 bits): 1 bit (S), 11 bits (E), 52 bits (m).Biais = 1023.E=
e+ 1023.
(Support de cours, T able 3.1, page 39)
1. Représentation de 5,75
Solution Détaillée

— Partie fractionnaire :0,75 10 = 0,5 + 0,25 = 1·2 −1 + 1·2 −2 = 0,11 2.

2e :

On identifie les composants :s= 0(positif),e= 2,m= 0111.

—E(8 bits) :E=e+Biais= 2+127 = 129 10.129 = 128+1 = 1·2 7+1·2 0 = 10000001 2.
—m(23 bits) : On complète0111avec des zéros :01110000000000000000000.
Étape 4 : Codage Double Précision (64 bits)

Comme la conversion binaire de 5,75 est finie, la représentation estexacte.

Exercice 16 : Système binaire simplifié (Facultatif)
Question :Analyser le code Python qui génère les nombres flottants d’un système simplifié.
Rappel du Cours
Le code Python (‘TD3-Exo16-TousNombresSaufDenormalises.py‘) simule un système en
base 2(radix= 2) avec :
—p= 3chiffres de mantisse au total.
— Exposantsedeemin=−2àemax= 3.
Un nombre normalisé s’écritx= (1,m) 2×2 e. Avecp= 3, la mantisse a 3 chiffres au
total (ex :1,00 2 ou1,11 2). La mantisseM(entière) va deMmin= 2 p−1 = 2 2 = 4à
Mmax= 2 p−1 = 2 3−1 = 7. La formuleM×radix∗∗(e−p+ 1)calculeM×2 e−3+1 =
M×2 e−2 = (M/4)×2 e.
—M= 4 =⇒(4/4)×2 e = 1,00 2×2e
—M= 5 =⇒(5/4)×2 e = (1 + 1/4)×2 e = 1,01 2×2e
—M= 6 =⇒(6/4)×2 e = (1 + 2/4)×2 e = 1,10 2×2e
—M= 7 =⇒(7/4)×2 e = (1 + 3/4)×2 e = 1,11 2×2e
Solution Détaillée
1. Retapez et lancez le script :Le script affiche un graphique avec des barres bleues
représentant tous les nombres (positifs et négatifs) que ce système peut générer.
2. Zoomer sur la zone proche de 0 :On observe un "trou" important entre 0 et le plus petit
nombre positif normalisé. Ce plus petit nombre normalisé est obtenu pour l’exposant
minimal (e=emin=−2) et la mantisse minimale (M=Mmin= 4) :
xmin_normal = 1,00 2×2 −2 = 1×0,25 = 0,25
Il n’y a aucun nombre normalisé représentable entre 0 et 0,25 (ni entre 0 et -0,25).
3. Suppression de la boucle pour les négatifs :Si on supprime la première boucle ‘for‘
(celle avec ‘range(emax, emin - 1, -1)‘), on ne génère plus les nombres négatifs. Le gra-
phique n’affichera que 0 et les barres bleues à droite de 0.
4. Ajout des nombres sous-normalisés (dénormalisés) :Les nombres sous-normalisés
(Support de cours, Déf. 3.2.3, page 38)comblent le "trou" autour de 0. Ils sont utilisés
quand l’exposant estemin=−2mais que la mantisse est de la forme0,m 2 (le ’1,’ im-
plicite disparaît). Dans le code (‘TD3-Exo16-TousNombresAvecDenormalises.py‘), cela
correspond aux boucles ajoutées :
—e = emin
—Mva de1àMmin-1(soit 1, 2, 3) pour les positifs.
—Mva de-Mmin+1à-1(soit -3, -2, -1) pour les négatifs.
Calculons ces nouveaux nombres (positifs) :
—M= 1 =⇒(1/4)×2 −2 = 0,01 2×2 −2 = 0,0001 2 = 0,0625
—M= 2 =⇒(2/4)×2 −2 = 0,10 2×2 −2 = 0,0010 2 = 0,125
—M= 3 =⇒(3/4)×2 −2 = 0,11 2×2 −2 = 0,0011 2 = 0,1875
Conclusion
En ajoutant les nombres sous-normalisés (0,0625, 0,125, 0,1875 et leurs négatifs), on
comble le "trou"entre 0 et 0,25. L’espacement entre les nombres devient régulier près
de 0, ce qui permet une "perte de précision gracieuse" (gradual underflow) plutôt qu’un
arrêt brutal à 0,25.

Exercice 17 : Système en baseβ(Facultatif)
Question :Calculer le nombre de valeurs normalisées pour un système en baseβ, avecpplaces
de mantisse, et exposantsE∈[E m,EM ].
Rappel du Cours
Pourβ= 2(notre cas IEEE-754), le bit implicite est1. Pourβ >2(commeβ= 10), la
convention est que le premier chiffre *après* la virgule est non nul (0,a 1a2...ap).
Un nombre normalisé s’écrit :x= (−1) s×(0,a 1a2...ap)β×β E aveca 1̸= 0.
Solution Détaillée
Nous devons compter le nombre de combinaisons possibles pours,E, et la mantisse.
—Signes (s) :2 choix (positif ou négatif).
—Exposants (E) :Le nombre d’exposants disponibles estE M−E m + 1. Comme
dans le cas binaire, on réserve les exposants extrêmes (min et max) pour les zéros,
infinis et NaN(Support de cours, Remarque 20, page 37). Nombre d’exposants
pour les normalisés :(EM−Em + 1)−2 =E M−E m−1.
—Mantisses (0,a 1a2...ap) :
—a 1 : ne peut pas être 0 (par définition de la normalisation pourβ >2). Il y a
(β−1)choix (de 1 àβ−1).
—a 2,...,a p : peuvent être n’importe quel chiffre de 0 àβ−1. Il y aβchoix pour
chacun desp−1chiffres, soitβ p−1 combinaisons.
Nombre total de mantisses :(β−1)×β p−1.
Le nombre total de valeurs normalisées est le produit de ces possibilités :
N= 2|{z}
signes
×(EM−Em−1)| {z }

×(β−1)β p−1

Conclusion
Application numérique :β= 10,p= 3,E m =−15,E M = 16.
— Signes : 2
— Exposants :16−(−15)−1 = 16 + 15−1 = 30
— Mantisses :(10−1)×10 3−1 = 9×10 2 = 900
N= 2×30×900 = 54000.
En ajoutant les deux zéros (positif et négatif), on obtient54002valeurs, ce qui corres-
pond au corrigé.
