Apache

Comment

et

Spark

Ce

Avec

Spark

Cela

4.
RDD
(Resilient
Distributed
Datasets)
:
Les
RDD
ou
Resilient
Distributed
Datasets
sont
l’un
des
concepts
fondamentaux
d’Apache
Spark,
permettant
le
traitement
de
données
massives.
a.
Comprendre
les
RDD,
l’unité
fondamentale
de
Spark
Il
s’agit
d’une
collection
distribuée
d’éléments
en
mémoire
qui
peut
être
gérée
en
parallèle.
RDD
est
un
acronyme
correspondant
à
:
●
Resilient
:
Capable
de
récupérer
rapidement
les
données
en
cas
de
problèmes
ou
conditions
difficiles
sur
un
nœud.
Les
objets
de
données
sont
stockés
dans
des
RDD
répartis
sur
le
cluster
de
données.
●
Distributed
:
Partage
les
données
sur
les
différents
nœuds
participants
pour
une
exécution
parallèle
(sorte
de
tableau
en
mémoire
qui
peut
contenir
plein
de
type
de
type
de
données
et
peut
être
divisé
sur
plein
de
machines).
●
Datasets
:
Une
collection
de
données
composées
d’éléments
séparés
mais
qui
sont
manipulés
comme
une
unité
compacte.
Les
RDD
utilisent
l’évaluation
paresseuse
,
c'est-à-dire
que
les
données
ne
sont
pas
chargées
dans
un
RDD
même
si
vous
le
déﬁnissez.
Les
transformations
sont
en
fait
calculées
lorsqu’on
appelle
une
action
comme
count();
collect()
ou
pour
enregistrer
la
sortie
dans
un
système
de
ﬁchiers.
Les
RDD
sont
immuables
,
c'est-à-dire
que
les
données
stockées
dans
un
RDD
sont
en
lecture
seule.
On
ne
peut
pas
modiﬁer
les
données
présentes
dans
le
RDD
mais
on
peut
créer
de
nouveaux
RDD
en
effectuant
les
transformations
sur
des
RDD
existants.
Les
RDD
effectuent
des
calculs
en
mémoire
.
Ils
stockent
toutes
les
données
immédiates
qui
sont
générées
dans
la
mémoire
(RAM)
aﬁn
de
fournir
un
accès
plus
rapide.
Un
RDD
peut-être
partagé
sur
plusieurs
machines
(Worker
Node)
dont
les
calculs
seront
synchronisées
via
un
Noeud

(Driver
Node).

On

❖

La

❖
L’action
:
Elle

qui

Chaque

Cependant,

nécessite

Création

RDD
:
Il

RDD
telles
que
:
❖
La
fonction
parallelize()
:
Segmente

collections
existantes
et
les
distribue
sur
les
workers
(plutôt
utilisé
lors
de
tests).
❖
L’utilisation
de
ﬁchiers
enregistrés
dans
un
support
local
(disque
dur
par
exemple).
❖
En
partant
d’autres
RDD.

12
/20]

On

L’architecture
