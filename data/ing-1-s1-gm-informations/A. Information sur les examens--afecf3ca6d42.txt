Tri par Fusion

Tri Rapide

Complexité : O(N2).

1. PROBABILITÉS CONDITIONNELLES & BAYES

P(A|B) = P(A∩B)/P(B)

Formule de Bayes

Probabilités totales

Applications types : spam, tests médicaux, alarmes, production défectueuse

2. DENSITÉS DE PROBABILITÉ

Vérifier qu'une fonction est une densité : ∫ f(x)dx = 1

Calculer la constante de normalisation C

Densités triangulaires/trapézoïdales ← très fréquent !

f(x) = C(a - |x|)1_{[-a,a]} ou similaire

3. FONCTION DE RÉPARTITION

F_X(x) = P(X ≤ x) = ∫_{-∞}^x f(t)dt

Relation f = F'

4. ESPÉRANCE & VARIANCE

E[X] = ∫ x f(x)dx

Var(X) = E[X²] - E[X]²

Théorème de transfert : E[g(X)] = ∫ g(x)f(x)dx

5. LOI EXPONENTIELLE ⚡

f(x) = λe^{-λx} 1_{[0,+∞)}

E[X] = 1/λ

Var(X) = 1/λ²

F(x) = (1 - e^{-λx})1_{[0,+∞)}

Propriété sans mémoire : P(X > x+y | X > x) = P(X > y)

6. TRANSFORMATIONS DE VARIABLES

Y = g(X) → trouver densité de Y

Méthode :

F_Y(y) = P(Y ≤ y) = P(g(X) ≤ y)

Dériver pour obtenir f_Y

Types fréquents : Y = X², Y = √X, Y = e^X, Y = ln(X)

7. INÉGALITÉ DE BIENAYMÉ-TCHEBYCHEV

P(|X - E[X]| ≥ ε) ≤ Var(X)/ε²

Usage : déterminer taille d'échantillon n

Intervalles de confiance

8. THÉORÈME CENTRAL LIMITE (TCL)

X₁, ..., Xₙ i.i.d., E[Xᵢ] = μ, Var(Xᵢ) = σ²

√n(X̄ₙ - μ)/σ → N(0,1) en loi

Approximation : P(a ≤ X̄ₙ ≤ b) ≈ Φ((b-μ)√n/σ) - Φ((a-μ)√n/σ)

9. LOI FAIBLE DES GRANDS NOMBRES

X̄ₙ = (1/n)∑Xᵢ → μ en probabilité

Applications à l'estimation

⭐⭐ TRÈS IMPORTANT (dans 50-70% des examens)

10. TYPES DE CONVERGENCE

Convergence presque sûre (p.s.) : P(lim Xₙ = X) = 1

Convergence en probabilité : ∀ε > 0, P(|Xₙ - X| > ε) → 0

Convergence en loi : F_{Xₙ}(x) → F_X(x)

Convergence L^p : E[|Xₙ - X|^p] → 0

Relations : p.s. ⇒ proba ⇒ loi ; L^p ⇒ proba

11. LOI UNIFORME

U([0,1]) ou U([a,b])

f(x) = 1/(b-a) sur [a,b]

Transformations à partir de U[0,1]

12. INTÉGRABILITÉ

Montrer X ∈ L¹ (E[|X|] < ∞)

Montrer X ∈ L² (E[X²] < ∞)

Astuce : si X bornée → automatiquement intégrable

13. VARIABLES I.I.D.

Indépendantes et identiquement distribuées

Base pour LGN et TCL

14. INÉGALITÉ DE MARKOV

P(X ≥ a) ≤ E[X]/a pour X ≥ 0, a > 0

P(|X| ≥ ε) ≤ E[|X|^p]/ε^p

⭐ RÉGULIER (dans 30-50% des examens)

15. LOI NORMALE (GAUSSIENNE)

X ~ N(μ, σ²)

f(x) = (1/√(2πσ²))e^{-(x-μ)²/(2σ²)}

Variable centrée réduite : Z = (X-μ)/σ ~ N(0,1)

16. LOI DE POISSON

P(X = k) = (λ^k/k!)e^{-λ}

E[X] = Var(X) = λ

17. RECORDS/MAX

Rₙ = max(X₁, ..., Xₙ)

F_{Rₙ}(x) = F_X(x)^n si X₁, ..., Xₙ i.i.d.

18. FONCTION CARACTÉRISTIQUE

φ_X(t) = E[e^{itX}]

Caractérise la loi

19. PARTIE ENTIÈRE

Y = ⌊X⌋ (partie entière de X)

Passage continu → discret
